# Security policy

`@duereason/action` is part of this repository (exported from DueReason's private monorepo). Please report
security issues privately rather than opening a public issue.

- Preferred: the contact form at https://duereason.com/contact (select "Security").
- RFC 9116 `security.txt` is served at `https://duereason.com/.well-known/security.txt` once an
  operator contact is configured; until then, use the contact form above.

Please mention `@duereason/action` explicitly so the report reaches the right maintainers, and include a
description of the issue and steps to reproduce if you have them.

## Supported versions

Only the latest published version of `@duereason/action` is supported with security fixes.

## Scope

This policy covers `@duereason/action` itself. It does not cover the DueReason or ReleaseKeep hosted
applications, which have their own disclosure channel via the contact form above.
